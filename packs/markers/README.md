# markers

Markers on the tape: set, name, cue, jump, loop and move sections. Part of **tape views 1**. Version 96. Needs nothing
else; [perform](../perform/README.md) needs it. With lanes' tall lanes the flags hang above the moved ruler;
without lanes or themes they sit in TE's own layout; without
punch, program changes go on to TE; without 8 tracks a move carries tracks 1-4.

Up to 16 markers a tape, one a keyboard key, kept inside the tape itself. On the tape screen:

| Gesture | Does |
| --- | --- |
| **HELP + a key** | set that key's marker at the play-head, on the beat |
| keep HELP held, turn the **1st knob** | name it: INTRO, VERSE, PRE, CHORUS, BRIDGE, BREAK, BUILD, DROP, SOLO, OUTRO, or a letter |
| **HELP + shift + key** | clear it |
| **shift + a marked key** | cue it: the tape goes there when the current section ends |
| the same twice quickly | jump now |
| shift + marked key **held 0.5 s** | loop that section (hold again inside the loop: release) |
| **HELP + left / right arrow** | previous / next marker |
| **HELP + 2nd turn** | time zoom: 1, 2, 4, AUTO, 8, 16, 32 bars across |
| HELP held: **3rd click, 3rd turn, 3rd click** | arrange: pick a section, move it, commit (tape stopped). One TE undo takes it back |
| any screen: **TAPE held + marked key** | the same cue |

A key that already has a marker is not moved: clear it, then set it. **Arrange moves audio on the tape**: try it on a
copy of a tape first. The markers live in TE's own tape file, so TE's tape copy and delete carry them on any base.
