# theme_console

A look for [themes](../themes/README.md): **CONSOLE**, an elbow header and pill lanes. Part of **tape views 1**.
Version 6. Needs themes (alone it loads and does nothing).

- **Tape screen:** the elbow header with the tape number, the big time and bar.beat, the transport as a shape and a
  word, the input; a loop sign and a cue countdown (`> BRIDGE IN 3.2`); marker flags; 8 lanes of pills, the selected
  track with a 2 px ring, muted audio as a thin line.
- **PERFORM face:** a set list (the playing row tall, a NEXT box with `AT` and `IN`), the punch-in strip.
- The mixer stays TE's own. CONSOLE costs less processor time than 89MPH.
